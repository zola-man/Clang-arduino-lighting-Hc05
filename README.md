# Smart Home Lighting System Using HC-05 Bluetooth Module 💡

A simple and practical IoT project that allows users to control home lighting wirelessly using a smartphone and the HC-05 Bluetooth module. This project demonstrates the integration of microcontroller hardware and mobile communication for smart home automation.

---

## 📘 Abstract
This project focuses on designing and implementing a **Home Lighting System** that enables users to control lights through Bluetooth communication. The system uses an **HC-05 Bluetooth module** connected to an **Arduino microcontroller** written in **C** Programming Language, allowing a smartphone app to send commands to turn lights ON or OFF.  
The project highlights how wireless technology can be leveraged to improve convenience, reduce power wastage, and promote energy efficiency. This simple yet effective system lays the groundwork for scalable smart home solutions.

---

## ⚙️ Features
- Wireless control of home lighting using Bluetooth
- Simple Android mobile app interface for user control
- Real-time ON/OFF feedback through indicator LEDs
- Low-cost, beginner-friendly IoT prototype
- Easily extendable for multiple appliances

---

## 🧩 Components Used
- Arduino UNO (or compatible board)  
- HC-05 Bluetooth Module  
- Relay Module  
- LED bulbs (or household lamps)  
- Jumper wires and breadboard  
- Android smartphone (with Bluetooth terminal app)

---

## 🧠 Working Principle
1. The **HC-05 Bluetooth module** establishes a wireless connection between the Arduino and smartphone.  
2. The user sends specific commands (e.g., "1" for ON, "0" for OFF) via the Bluetooth app.  
3. The Arduino receives these commands and triggers the **relay module**, controlling the lights accordingly.  
4. LED indicators provide feedback to show the current status of each light.
